# 해상왕 장보고 런처

`Changpogo.exe`를 원본 그대로 실행하면서 최신 런처 업데이트와 저지연 실행 환경을 제공하는 Windows 런처입니다.

## 주요 기능

- 게임 실행 파일 자동 탐색 및 경로 저장
- 저지연 실행 모드: 1ms 타이머 해상도, 높은 프로세스 우선순위, 우선순위 부스트
- GitHub Releases 우선, `update.json` 보조 방식의 자체 업데이트
- ZIP 검증, 기존 파일 백업, 실패 시 롤백, 자동 재시작
- 원본 `Changpogo.exe`와 게임 데이터는 변경하지 않음

## 반응 지연에 관하여

대상 빌드(SHA-256 `16E4C3D3D17438928839A09901A4159DA154EB0EC822C784856707B77F9F4B1F`)는 `NetTurn` 기반 동기 명령 처리와 별도 네트워크 펌프를 사용합니다. 확인되지 않은 고정 오프셋 패치는 멀티플레이 동기화 오류를 만들 수 있으므로 이 버전은 안전하게 검증 가능한 운영체제 스케줄링·타이머 지연만 줄입니다.

저지연 모드는 로컬 입력·스케줄링 지연을 완화하지만, 멀티플레이에서 다른 참가자의 명령을 기다리는 네트워크 턴 자체를 제거하지는 않습니다. 싱글플레이와 멀티플레이를 각각 비교해 주세요.

## 사용법

1. `ChangpogoLauncher.exe`를 실행합니다.
2. 경로가 다르면 `찾기`에서 `Changpogo.exe`를 선택합니다.
3. `저지연 실행`을 켜고 `게임 실행`을 누릅니다.
4. 새 배포 버전은 `런처 업데이트` 버튼으로 적용합니다.

기본 경로는 `C:\Users\seo\Downloads\DGGL\Games\Changpogo_Win_260708\Changpogo.exe`입니다.

## 빌드와 배포

```powershell
.\build.ps1
.\package.ps1 -Version 1.0.0
```

생성된 `dist\ChangpogoLauncher-1.0.0.zip`을 GitHub Release의 `v1.0.0` 태그에 첨부합니다. Release가 없다면 저장소의 `update.json`을 사용합니다.
