# 1.5.1 멀티 75ms 시험판

1.5.0의 100ms 처리 주기를 75ms로 줄인 별도 시험판입니다.
양쪽 모두 기존 게임을 완전히 종료하고, 새 폴더에 압축을 풀어 이 버전으로 실행하세요.
다른 버전과 혼용하지 마세요. 런처는 상대방 버전을 자동 검증하지 못합니다.

- 명령 처리 목표 주기: 75ms (1.5.0은 100ms)
- 대기 묶음: 원본 3 유지
- 원본 200ms당 게임 진행량 보정: 0.375 (= 0.5 × 0.75)
- 동기화 보정의 시간 상수: 75ms, 보정 한계 ±74ms
- 준비 상태 검사·동기화 보정 분기 유지
- 싱글 50ms 패치·미니맵 설정 유지
- 게임 EXE 디스크 파일 변경 없음, 프로세스 종료 시 패치 해제

검증: 실제 x86 코드 모의 실행, 호스트/참가자 모드, 네 가지 게임 속도,
20초 누적 진행량(원본 한 묶음 이내 초기 차이), 재배치, 준비 대기,
싱글/멀티 분기 및 리소스 재생성 일치. 실제 LAN 동기화·진행 속도와
체감 반응 개선은 확인 전입니다. 단순 모의 실행을 실제 게임 검증으로 보지 마세요.

먼저 짧은 새 경기에서 이동·공격 반응, 유닛 상태 일치, 게임 속도를 확인하세요.
끊김·상태 불일치·비정상 속도가 발생하면 경기를 종료하고 양쪽 모두 1.5.0으로 돌아가세요.
1.5.0 폴더는 보관하세요. 일반 자동 업데이트는 1.4.6으로 유지됩니다.

빌드: build.ps1 -OutputDirectory bin/experiment-1.5.1 -Multiplayer75ms
검증: py -3 tools/test_multiplayer_cadence.py GAME_EXE --75ms
